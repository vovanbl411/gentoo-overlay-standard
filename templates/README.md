# Шаблоны для оверлея

Заготовки подготовлены для [Standard v0.2](../STANDARD.md).
Выберите материалы под свой профиль и замените заполнители `⟨…⟩`
фактами о проекте. Существующие имена, команды и расположение файлов
подходят, если выполняются применимые требования.

| Что нужно | Материал |
| --- | --- |
| Помочь пользователю установить и обновить пакеты | [README RU](overlay/README.md) и [README EN](overlay/README.en.md). Сверьте команды, версии и ограничения между языками. |
| Обозначить рамки сопровождения | [AGENTS.md](overlay/AGENTS.md) со ссылками на действующие правила. |
| Объяснить путь автоматизированного обновления | Необязательный [AUTOMATION.md](overlay/docs/AUTOMATION.md). Подходит, когда описание потока перегружает README или справочник по эксплуатации. |
| Настроить проверки и описать восстановление | [CI_AND_SECURITY.md](overlay/docs/CI_AND_SECURITY.md). При небольшом объёме используйте существующий документ сопровождения. |
| Подобрать конфигурацию инструментов | [CI](overlay/.github/workflows/ci.yml), [Dependabot](overlay/.github/dependabot.yml), [.gitignore](overlay/.gitignore). |
| Подготовить решение о внедрении | [Чек-лист](adoption-checklist.md) с доказательствами на конкретной ревизии. |

Один документ может описывать весь поток обновления. Разнести установку,
путь кандидата и диагностику по отдельным страницам удобно, если их
читают в разных ситуациях. Такой подход показывает
[пример Noctalia](../docs/update-workflow-reference.md#пример-noctalia).

## Как адаптировать CI

- Пример запускает только Python unit-тесты. В фильтрах `pull_request`
  и `push` подставьте принятую ветку, если она называется иначе.
- Из корня оверлея с Python 3 запустите
  `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts/tests -p 'test_*.py' -v`.
  `-s` задаёт каталог тестов, `-p` — имена файлов, `-v` выводит
  результат каждого теста. Переменная окружения отключает запись
  `.pyc`. Подставьте фактический каталог, проверьте импорты и нужные
  тестовые файлы. В отчёте должно быть видно, что выполнены применимые
  тесты: нулевой набор не подтверждает V1.
  [Эксперимент с расположением тестов](../audits/test-layout.md)
- Перед сменой имени, источника check или запускающих событий сверьте
  effective rulesets и legacy protection по G2. Учтите порядок
  одобрения запусков для automation PR.
- Для кандидатов определите отдельные проверки источников, метаданных и
  Manifest, а resolver, сборку и runtime добавьте там, где их требует
  локальная политика. [Матрица проверок](../STANDARD.md#проверки-и-доказательства)

Пример Dependabot предлагает еженедельные обновления GitHub Actions.
При адаптации `.gitignore` проверьте, что намеренно отслеживаемые пути
остаются доступны Git.
