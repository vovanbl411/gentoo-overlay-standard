# Gentoo Overlay Standard

Этот репозиторий хранит общие инженерные требования для Gentoo-оверлеев
`vovanbl411`. Каждый оверлей остаётся самостоятельным репозиторием и
определяет собственную политику упаковки и принятое состояние.

## Phase 0. Инвентаризация и аудит

[Базовый аудит](audits/baseline.md) принят в коммите
`638130a268da300cda9cd5ac3abb6e053691b409`. В нём зафиксированы ревизии и
результаты сравнения Zed, Noctalia, Umbriel, Luciole, Spotatui, ASUS NumberPad
и Coucou. Vicinae и Spotify Player архивированы и исключены из миграции.

## Phase 1. Проект стандарта

[Standard v0.1](STANDARD.md) подготовлен для ревью владельцем. Он описывает
общие требования и профили сопровождения, границы публикации и критерии
проверки. Решение об утверждении стандарта и внедрении в каждом оверлее
принимает владелец. Текущая фаза ограничена документацией и сверкой с
аудированными ревизиями. [Правила работы с репозиторием](AGENTS.md)
