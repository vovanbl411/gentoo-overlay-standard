# Gentoo Overlay Standard

Этот репозиторий предназначен для общих инженерных соглашений Gentoo-оверлеев
`vovanbl411`. Здесь будут храниться согласованные требования и эталонные
шаблоны для документации, интерфейсов автоматизации, проверок и сопровождения.
Каждый оверлей остаётся самостоятельным репозиторием. Правила упаковки,
совместимости и отката учитывают особенности конкретных пакетов.

При выборе соглашений отправной точкой служат решения, уже проверенные
в существующих оверлеях. В текущую архитектуру не входят общие зависимости
времени исполнения, reusable workflows, общие Python-пакеты, генераторы,
submodules и автоматическая синхронизация.

## Phase 0. Инвентаризация и аудит

[Исходное состояние оверлеев](audits/baseline.md) фиксирует ревизии и результаты
сравнения Zed, Noctalia, Umbriel, Luciole, Spotatui, ASUS NumberPad и Coucou.
Vicinae и Spotify Player архивированы и исключены из миграции.

В Phase 0 проводится инвентаризация. Утверждение соглашений, создание
шаблонов и миграция оверлеев требуют отдельного решения владельца. Правила работы с
репозиторием описаны в [AGENTS.md](AGENTS.md).
