# Gentoo Overlay Standard

Gentoo Overlay Standard помогает создавать и сопровождать Gentoo-оверлеи.
Он объясняет, как связать версию со скачанными исходниками, проверить
файлы перед PR и выяснить, где остановилось обновление. Владелец решает,
когда проверенное изменение становится частью принятой ветки.

У каждого оверлея свои пакеты, правила версионирования, проверки и
условия отката. Общие требования помогают сравнивать результаты, а
самостоятельные реализации позволяют менять один оверлей без общей
инфраструктуры и без влияния на работу остальных.

Действует [Standard v0.2][accepted], принятый владельцем.

## Выберите профиль

| Профиль | Когда подходит |
| --- | --- |
| Manual | Сопровождающий сам выбирает источник, готовит и проверяет обновление. |
| Release | Автоматизация готовит обновления из релизов upstream. |
| Snapshot | Автоматизация готовит обновления из точных коммитов upstream. |
| Extended Release | Путь Release дополнен отдельной публикацией файлов, когда она нужна пакету. |

Профиль описывает способ обновления. Пакеты с ручным обновлением в
автоматизированном оверлее следуют общим требованиям.

## Если вы создаёте оверлей

1. Определите, какие пакеты и конфигурации будете поддерживать, откуда
   берёте исходники и как будете принимать обновления. Выберите профиль.
2. Сверьте структуру и применимые проверки со [стандартом](STANDARD.md).
   Возьмите из [шаблонов](templates/README.md) те материалы, которые нужны
   для установки, проверки и сопровождения.
3. Пройдите первое обновление по [практическому руководству](docs/update-workflow-reference.md).
   Запишите результаты и оформите решение о внедрении по
   [чек-листу](templates/adoption-checklist.md).

## Если оверлей уже работает

1. Выберите точную ревизию оверлея и отметьте в
   [чек-листе](templates/adoption-checklist.md), что применимо к его пакетам.
2. Сопоставьте действующее поведение, проверки и настройки GitHub с
   требованиями. Сохраняйте рабочие решения, если они выполняют контракт.
3. Устраните подтверждённые разрывы или согласуйте допустимые исключения.
   Зафиксируйте доказательства и решение владельца для выбранной версии
   стандарта и этого оверлея.
